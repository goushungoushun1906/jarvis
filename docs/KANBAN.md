| 数据库 disk I/O error | 高 | `integrity_check` 返回 ok、`os.access(W_OK)` 为 True，但写入报 `attempt to write a readonly database`。用 `iterdump()` + 完整语句分割器重建（**不能直接按换行 split**，多行 CREATE TABLE 会被切碎）；FTS 虚拟表要单独 CREATE，sqlite_master 里的元数据 INSERT 不会真建。两个库均已修复 | 已完成，99 会话 / 543 消息完好 |

### 已完成（本轮根因排查）

| 结论 | 证据 |
|------|------|
| **不是前后端没连上** | 后端日志 `engine=sherpa rate=16000 frame=512 keywords=['你好贾维斯']`；前端调了 `/api/wakeword/start` 与 `/stream`；SSE 持续推 level 事件 |
